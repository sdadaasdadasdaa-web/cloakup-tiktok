# Renomeação do projeto

O nome do repositório e do domínio foi alterado de `cloaker-tiktok` para `cloakup-tiktok` para não conter a palavra "cloaker" e evitar problemas com campanhas de anúncios.

## O que mudou
- Nome do repositório: `cloaker-tiktok` -> `cloakup-tiktok`
- URL do GitHub: https://github.com/sdadaasdadasdaa-web/cloaker-tiktok -> https://github.com/sdadaasdadasdaa-web/cloakup-tiktok
- URL da Vercel: cloaker-tiktok.vercel.app -> cloakup-tiktok.vercel.app (novo deploy)

## Importante
- O repositório foi renomeado via API do GitHub. Se você clonou o repositório, atualize o remote:

    git remote set-url origin https://github.com/sdadaasdadasdaa-web/cloakup-tiktok.git

- Faça um pull para trazer a mudança:

    git pull origin main
